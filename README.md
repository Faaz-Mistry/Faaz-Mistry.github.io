# Faaz Mistry – Portfolio

Static one-page site (no build step): `index.html`, `img/`, and the resume PDF.

## Edit
All text lives in the block marked `EDIT HERE` near the bottom of `index.html`.
- Add a project: copy an entry in `PROJECTS`, add its screenshot to `img/`.
- Tool filters and the "Coming soon" line update automatically.

## Deploy (GitHub Pages)
1. Create a repo and push these files to the `main` branch.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. Each push to `main` redeploys. The site appears at `https://<username>.github.io/<repo>/`.
   (Name the repo `<username>.github.io` to get `https://<username>.github.io/`.)
